# NASA Space Apps Challenge 2026

## Description

This project is an early version of a lunar base management game developed for the NASA Space Apps Challenge 2026.

During development, the direction of the game was reconsidered, and the project has since transitioned to a 3D space-based game.

## Development Status

Development in this repository has ended and is now continuing in the following repository:

➡️ [LunaInsidious/NASA-SpaceApp](https://github.com/LunaInsidious/NASA-SpaceApp)

Some of the features and ideas developed in this project have also been carried over to the new project.

## Supported Platforms

Due to usability considerations related to the transition to 3D and limited development time, development is currently focused on **PC browsers**.

Mobile support is not available at this time.

## Future Plans

The following improvements may be considered in the future:

- Responsive design
- Mobile browser support
- More intuitive controls

## About This Repository

This repository is preserved as a record of the early development of the lunar base game.
